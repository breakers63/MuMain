# Paris right shortcuts

Four gold icons open Menu, Missions, Events and Reset. Labels appear on hover; shortcuts hide while custom or blocking game panels are open. The old bottom Menu button is hidden. Reset opens its panel, without executing a reset.

The RML anchor and container require an explicit 104dp height and block icon display for reliable rendering in the live client. The shared atlas is Paris_RightShortcuts.OZT. Base, legacy, modern and paris-gold styles are included.

Validated with RML layout previews and in the live paris-gold client at 1024x768, including custom-panel hiding.
