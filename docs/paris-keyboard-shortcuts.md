# Paris custom shortcuts

The OpenGL and Vulkan clients use the same shortcuts. Press again to close the window.

| Window | Shortcut |
|---|---|
| VIP | Ctrl+V |
| Ranking | F7 |
| Jewel Bank | Ctrl+J |
| Character info | Ctrl+I |
| Market | O |
| Reset | Y |
| Events | H |
| Add Stats | S |
| Battle Pass | Ctrl+B |
| Kill Log | Ctrl+K |
| Post Item Log | Ctrl+P |

Shortcuts are disabled while typing, in transaction dialogs, and during confirmation dialogs.
Personal shop now uses Ctrl+S to keep S available for Add Stats. Regular J, V, I, B and P retain their existing actions.

The Paris helper bar is at the upper-left corner with the live map and coordinates, settings, and a Start/Stop button reflecting the real helper state. Vulkan Legacy and Legacy Inherited keep their original bar art. Home continues to start/stop the helper; Z opens settings.
