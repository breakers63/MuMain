# Store price and legacy RGB routing

The store-price request and legacy RGB request collided on FA/E8. The server now registers RGB on D9 and dispatches only the exact legacy 50-byte C1 FA/E8/version-1 envelope to its enabled RGB handler. The 11-byte E8 price request remains owned by the market price handler. Existing clients need no packet format changes; malformed packets are not treated as legacy RGB. Ten focused routing, price and dye tests passed.

Vulkan also closes an open skill grid before the global Escape handler opens the system menu, retaining modal dialog priority. Compiled Windows release: 2026.10.25.4. Live gameplay confirmation remains necessary.
