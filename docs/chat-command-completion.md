# Ayuda de comandos del chat

Escribe `/` en el campo del mensaje para ver comandos y descripciones en español.
La lista se filtra mientras escribes. Usa arriba/abajo para recorrerla y haz clic para
completar el nombre. El clic no envía el comando: revisa sus argumentos y pulsa Enter.
Los comandos de GM se muestran únicamente para operadores. Al escribir argumentos
se conserva la ayuda del comando exacto. Al salir del chat se oculta la lista.
La lista es una referencia local: el servidor sigue validando permisos y disponibilidad.
